Citizen Collector

It watches Star Citizen while you play and writes down what the game already records, so the community can build a better map of prices, ships and places. It is free, it is not selling anything, and you can delete it by deleting its folder.

Windows will warn you about this download. Here is exactly what you will see.

The program is not code-signed. Code signing costs a few hundred a year and this project takes no money, so it is not signed. Windows treats anything unsigned as suspicious.

When you run it you will get a blue box that says “Windows protected your PC”. It does not offer a Run button until you look for one:

  1. Click More info — the small link in the box.
  2. Click Run anyway, which appears after you do.

Your antivirus may also quarantine it, and the reason is not mysterious: this program reads files, takes screenshots and uploads. That is a fair description of what a scanner is built to be suspicious of, and it is also a fair description of what this program honestly does.

Do not turn your antivirus off. Nobody should talk you out of your scanner on the strength of a paragraph on a web page. If you are not comfortable, the better answer is to read the source — all of it is public — or to not install it. Both are reasonable.

Download

Get the latest release

Downloads come from GitHub. collector.exe is the program on its own; the .zip is the same thing with a readme and a settings file.

Every release lists a SHA256. If you want to check what you downloaded is what was published, run Get-FileHash collector.exe in PowerShell and compare it.

What it does not do

  • It does not modify the game. No injection, no code in the game's process, no reading the game's memory, no automating play. It reads a text file the game already writes, and takes ordinary screenshots.
  • It does not read any window except Star Citizen's. It checks the window belongs to the game before it looks.
  • It does not read chat. Not filtered, not scrubbed, never sampled.
  • It does not send anything without your say-so. When you set it up it asks you one question: send automatically when you stop playing, or ask every time. It then does exactly what you picked. You can change it whenever you like.
  • It does not delete anything the server has not confirmed receiving. A failed send costs you nothing.
  • It does not want your email address. There is no signup, no account and no form on this page for a reason.

Before you install it, know this

It takes pictures of your screen while you play, and those pictures are part of what gets sent. A picture can show your handle, the handles of other players near you, and anything else the game had on screen. They are read by us for prices and stock, they are never published, and nothing taken out of them carries anybody’s name.

The program says all of this on its first screen, and does not collect anything until you agree to it there.
