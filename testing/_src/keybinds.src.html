Your Star Citizen keybindings — check them, change them, save them

Nothing here touches the game. You work on a copy of your profile and export a file, which you then put back into Star Citizen yourself.

  1. Import your profile — the Profile bar below. In the game: Options → Keybindings → Control Profiles → Save, then pick that file here.
  2. Find the action you want — search or pick a category in Every action the game defines further down. All 691 of them.
  3. Click its binding and press the key you want. Clicking × clears one instead.
  4. Export when you are done, and load that file back in the game.

The keyboard below is a tester, not an editor. Press any key and it shows you what that key currently does — useful for finding a free one. Capture decides whether the page listens to your keys; Keyboard/Mouse, Gamepad and Joystick switch which device you are looking at.
