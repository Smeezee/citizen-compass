# Citizen Compass

Free fan-made Star Citizen ship reference tool — find out where to buy a ship in-game with aUEC, or with real money on the RSI Pledge Store, before you go looking for it.

- **Live site:** [citizencompass.netlify.app](https://citizencompass.netlify.app)
- **API:** [citizen-compass-production.up.railway.app](https://citizen-compass-production.up.railway.app)

## Stack

PostgreSQL + FastAPI + a static HTML/CSS/JS frontend, backing a ship purchase matrix covering 232 ships across 18 manufacturers.
