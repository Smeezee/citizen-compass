## QUESTION 1 — WHEN DOES A SWAP HAPPEN?

**A — Fit is the commit.**

- Preview never installs.
- **Fit** writes that hardpoint into the working loadout immediately.
- **Cancel preview** backs out with no change.
- **Undo** = one step: undo the last Fit on that hardpoint (label names the component). Not a free multi-stack for this pass.
- **No** separate “Commit loadout” required for a swap to be real.

**Why the mock disagreed:** the PNG was an illustrative render. The footer line *“undone until you commit the loadout”*, the `NovaPilot` account chrome, and the orphan `CHIP` label are **invented mock dressing**, not the written package. **The memo wins over the PNG wherever they conflict.**

**Navigate-away / tab close:** working loadout may persist in local browser storage as a convenience (same as today’s draft behavior if any) — that is persistence of A, not product B. It is not “stage until Save.” If we later add **Save** / **Share**, those mean *name or export a loadout snapshot*, not “finally apply the Fits.”

**Header Save / Share in the memo:** keep as *future/export* affordances, not as the swap commit. Mock must not imply accounts.

## QUESTION 2 — WHERE DOES MEANING COME FROM?

**Generated, never hand-authored per component pair.**

v1 rule:

1. **Meaning is a short template over the same structured delta fields shown in Difference** (stat key → canned phrase fragments: e.g. range up → “longer lock range”).
2. **It must not invent facts** not present in those fields.
3. **If the template would only parrot the Difference line with no extra clarity, hide Meaning for that row** (Difference stands alone). Width is earned only when the sentence helps a non-expert.
4. **Not** a thousand hand-written pair blurbs. **Not** an LLM call in the page for this pass.

So: Meaning is optional assistive copy, generated from deltas, droppable per row. Difference with honest units is the load-bearing column.

## THREE SMALLER — AGREED, FIX THE MOCK / SPEC

**1. Difference units**  
Show **value + change** (or change **with base**). No bare `%` without base. Do not mix unlabeled `%` and absolute in one undifferentiated list — each line carries its unit and baseline. Same lesson as burst/sustained.

**2. Mode chips**  
Live on the **decision strip**, next to the comparison they govern — not on the viewer. Label is **`vs fitted` | `vs stock` only**. The mock’s `CHIP` was a placeholder artifact; delete it.

**3. Status column**  
**`Unchanged`**, not green **`OK`**.  
`OK` claims verification we may not have. Verification (when `last_verified_patch` exists) is a **separate** mark — never smuggled into “nothing edited here.”
