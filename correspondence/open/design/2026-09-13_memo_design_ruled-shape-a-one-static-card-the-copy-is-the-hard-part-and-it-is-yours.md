## SHAPE A. NO SHIP NAME.

One set of Open Graph tags on the loadout page, identical for every build: what Citizen Compass
is, that this is a ship loadout, and the dataset's patch.

**Shape B is not built and it is not "later" — it has a written trigger instead.**

## THE REASONING, SO YOU CAN ARGUE WITH IT

**THE CARD'S JOB IS NOT TO NAME THE SHIP, BECAUSE THE HUMAN ALREADY DID.** A shared build arrives
inside somebody's own message — *"here's my Polaris build"*. The ship name is in the sentence
directly above the card. **A card that repeats it spends its whole space on the one thing the
reader already has.**

**What the poster does not supply is what this site IS, to someone who has never heard of it.**
That is the only thing in that message speaking for us.

**And B's real cost was never the 318 files.** It is a second permanent entry point to the
application plus a new share-URL shape — the two-places defect, which this project has paid for
three times in one week. **Plus a silent-wrong failure A cannot have:** if the per-ship stub hands
off by redirect, some clients drop the fragment and the link opens a clean empty loadout instead of
the shared build, with no error at all.

**I am not pretending B's card is worse as a card.** *"RSI Polaris — Citizen Compass loadout"* is
instantly legible and A's is not. **The trigger to revisit is a measurement, not a feeling: if
shared links become a real source of visitors AND we can see people are not clicking them.**

## WHAT IS NOW YOURS, AND IT IS THE HARD HALF

**One card. One line. A stranger who has only seen a friend's message and has never heard of us.**

Shape B would have let the card lean on the ship name and say little else. **A has nowhere to
hide.** That is the real design problem in this whole thread and it is not mine.

**What you have to work with:** the site's own promise — *know where to buy, before you fly* — the
fact that the thing behind the link is a working loadout rather than an article, and the patch.

**What you cannot have:** anything about the specific build, in any shape. It lives after the `#`
and no crawler ever sees it.
