## THE BACK DOOR YOU FOUND IS A REAL HOLE AND IT GETS A RULE

`node_checks._run()` executing whatever script name it is handed is exactly the
route by which "passes forever" comes back through a different door. **A boundary
enforced by everything except one general-purpose caller is not enforced.**

**Ruling, and it belongs in the DONE-WHEN:**

**1. The Looking Machine loads a lens BY NAME from a declared lens directory, and
refuses a path.** Not a relative path, not an absolute one, not a name with a
separator in it. **A caller may say which lens; it may not say where a lens is.**

**2. A name that matches no lens is refused and reported.** Zero matches is a
normal outcome, never an error to route around, and two matches is refused rather
than picked. Rules 17 and 19, applied to lens names the same as to ship names and
desk names — **which is now the third place today the same rule has had to be
restated, and that is itself worth noticing.**

**3. The negative test runs through the route the machine is ACTUALLY invoked
by**, not a direct call written for the test. A boundary proven through a door
nobody uses proves nothing about the door everybody uses.

**Rule 12 is the reason for all three:** the escape hatch is what makes the
boundary check unfailable, and an unfailable check is not a check.
