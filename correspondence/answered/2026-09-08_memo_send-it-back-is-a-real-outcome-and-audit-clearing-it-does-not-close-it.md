## THE SHAPE YOU ASKED FOR

**The letter never becomes a new letter and never gets renamed. That is the whole
design.** Everything else follows from it, because a new file is precisely how the
thread gets lost.

    Status: Answered      →  Answered  →  Returned  →  Answered  →  ...
    Rounds: 1                2           3            4

**A return is a MOVE, not a post.** The file goes from `correspondence/answered/`
back into `correspondence/open/<the desk that answered it>/`, and a dated block is
appended:

    ## ROUND 3 — RETURNED by <desk>, <date>
    WHY THE ANSWER FAILED   <the specific thing, not "wrong">
    WHAT WOULD SATISFY IT   <what a good answer looks like>

**The original question is never edited.** Neither is any earlier round. **Six
months from now the file reads as what actually happened**: the question, the answer
that failed, why it failed, and what came next — in order, in one place.

## THE FOUR RULES THAT MAKE IT WORK

**1. IT DOES NOT GO THROUGH `inbox/`.** This is the one thing that would break it.
The watcher timestamps and renames anything dropped there, so a return posted as new
post comes back with a new name and the thread is lost — the exact failure the third
state exists to prevent. **A return is a file move between two folders that already
exist.** No new mechanism.

**2. A RETURN WITHOUT A STATED REASON IS NOT A RETURN, it is a new question.** The
whole value is that the failure is on the record. "Try again" teaches nobody
anything, and in six months it reads as a desk being difficult rather than a desk
being right.

**3. IT GOES TO THE DESK, NOT TO YOU.** Your line holds — a technical problem goes
back to the desk, a changed intention comes to you.

**4. THREE ROUNDS AND IT STOPS BEING CORRESPONDENCE.** A letter that has failed
twice is no longer a question being answered badly; **it is two desks that disagree,
and that is the case that genuinely comes to you.** Without a cap this state is an
invitation to ping-pong, and the cap is also what makes the escalation honest — it
arrives with its own complete history attached rather than as somebody's summary of
a dispute.

## WHAT THE CHECKER WOULD ASSERT, WHEN IT IS BUILT

Every file in `answered/` ends in an answer block, not a return. Every file in a
tray reading `Status: Returned` carries a reason line. Round numbers only ever go
up. **Any letter at round 3 is reported, not blocked** — flag, never gate.
