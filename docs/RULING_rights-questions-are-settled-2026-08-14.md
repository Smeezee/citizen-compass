## What is settled

**Compliance is established by the existing practice**, not by a further
approval anybody is waiting on:

- **Everything goes to the testing site first and is verified there** before it
  reaches anyone. That is the control, and it has been the control for months.
- **The site URL has not changed.** It is the same Netlify address it launched
  under. The Fan Kit notification obligation attaches to the URL and to a change
  of domain; there has been no change, so there is nothing outstanding to notify.
- The project remains free, non-commercial, and operating as a fan site under
  the terms it has always operated under.

**This covers the rights topic as a whole** — the Fan Kit Agreement, the site
URL notification, and reading RSI's own public surfaces. Sleven ruled on the
conversation, not on one sub-question of it.

## WHY THIS FILE EXISTS — read this part before raising anything adjacent

`CURRENT-STATE.md` carries a section titled **"Open, and only Sleven can do
these."** Every session is instructed to read that document first. It lists the
rights items as open. So every session dutifully reads it, sees "open", and
raises it again — and Sleven answers the same question for the fourth or fifth
time.

**The document was the cause, not anybody's memory.** A session doing exactly
what it was told to do produced the loop.

**So: the list in `CURRENT-STATE.md` is not a prompt to ask.** Items on it are
recorded so nobody assumes they are done. They are not an invitation to raise
each one at the start of a session. If an item there has a ruling doc like this
one, the ruling wins and the list entry is stale — say so and move on rather
than asking again.

## What a session should do instead

- **Do not re-raise this.** Not as a question, not as a caveat, not as "just
  flagging for awareness". Flagging is raising.
- **Do not attach it as a rider** to unrelated work. "Ship it, though note the
  rights question" is the same behaviour wearing a hat.
- If genuinely new circumstances arise — a domain change, a move to
  monetisation, a request from CIG — that is a **new** fact and may be raised
  as one, naming what changed. Nothing else qualifies.

## Still genuinely separate, and NOT covered by this ruling

**The 5,344 CIG-written item descriptions.** That is a different question with a
different answer, and it stays closed for a different reason: they must not
ship, nothing deployed carries them, and the position on record

— ship the keys and the facts, hold CIG's prose. **That is a settled
instruction, not an open question either.** Do not raise it as one. The 238
descriptions that did ship are Citizen Compass's own text, written from scratch,
which is why the `real_cig_desc()` gate exists.
