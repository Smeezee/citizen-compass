## 2. The things actually open

### 2A. All four names — and the unnamed-ship angle is the way in

**The strongest lead is not the names. It is CIG's own unnamed 2026 ships.**

CIG has confirmed unnamed Drake and Origin ships in development. **Find out what
those are.** If a transcript, a Spectrum dev reply or the Progress Tracker names
either of them, that either matches one of these leaked names or rules it out —
and that is a real answer instead of an absence.

Then, per name:

**Drake Marauder.** Is there any Drake vehicle by that name, at any status? Drake
is a prolific manufacturer and the name fits their style. Also check whether
"Marauder" has ever been used by CIG as a Drake *concept* name that was later
renamed — that happens.

**Origin M60.** Origin has an M50 and an M80. An M60 fits the slot exactly. Is
there any sign of one, at any status?

**RSI Skylark.** A "Skylark" paint for the RSI Meteor exists — that is confirmed.
The question is whether a *ship* by that name also exists. Sleven says he has
heard the name before, so do not treat the paint as closing it.

**GATAC Hyun.** Gatac's public roster is Railen, Syulen, Tyilui. Nothing called
Hyun. Gatac uses Xi'an-derived naming, so try alternate spellings and
apostrophes. A clean "no" is a perfectly good result here.

rework or a Gatac Hyun was mentioned at all, a broadcast is where.

Pull captions/transcripts and search them. YouTube auto-captions are usually
available via the transcript panel under the video.

### 2D. Reddit — signal only, never evidence

r/starcitizen and r/starcitizen_refuge. **Use it to find the trail, not as the
answer.** What is wanted from Reddit is a *pointer*: "this was said in ISC episode
X" or "here is the dev reply". Then go and read that primary source and cite it.

**A Reddit thread is never a source for a fact about CIG's plans.** Plenty of
them are people repeating the same leak back to each other, which reads as
corroboration and is not.

## 3. Evidence rules — these decide whether the work is usable

**Counts as official:** CIG's own site, a comm-link, a CIG developer's tagged
Spectrum reply, or something a named CIG employee says on an official broadcast.

**Does not count, no matter where it sits:** player posts on Spectrum — including
on robertsspaceindustries.com, which is a trap. The previous pass hit a fan-made
*"[Concept] Drake 'Marauder' Gunship"* post sitting on CIG's own domain that looks
official at a glance. Reddit. Fan news sites. YouTube commentary channels
discussing a leak.

**No leak aggregators.** Not as a source, not as a lead, not as "let me just check
what they said". If a page is republishing a leak, close it. This whole job exists
because a leak list turned out to be roughly half wrong.

**Say which tier every fact came from.** A page that repeats another page is not a
second source.

## 4. What a good result looks like

Not "I found something". A good result is any of:

- a transcript quote with episode, date and timestamp
- a CIG dev's Spectrum reply, quoted, with the URL
- a Progress Tracker card, named and dated
- **or a clear, confident "I read all of this and CIG has said nothing"**

**That last one is a real answer and it is worth as much as a find.** Two passes
already point that way for the Constellation. If a third confirms it from the
sources only you can read, the question is closed properly instead of left open.
