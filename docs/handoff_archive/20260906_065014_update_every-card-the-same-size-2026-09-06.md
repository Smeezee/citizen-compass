# update - every card is now the same size, 2026-09-06

Sleven: *"There's a couple sections where the boxes don't all match. There's
uneven gaps... all boxes should be the same, unless you can explain to me why it
shouldn't."*

**He is right and there is no good argument against it.** The cards were sized to
their own content, so any ship carrying a note, a second dealer price or a
wrapped name pushed taller than its neighbours and left ragged gaps down the
column. That is the difference between a page that looks designed and one that
looks assembled.

Fixed: every card is now exactly the same height, with the inside laid out on
fixed rows - name, specs, price, shop, then the note pinned to the bottom edge so
notes line up across a row instead of floating at whatever height the text above
them ended.

## The one real cost, stated rather than hidden

A fixed box means a long note can be cut off. It already clamped at two lines;
now it also clips at the card edge. **The full note is never lost - it is on the
ship page** - but a reader who only looks at the card may see a sentence end in
nothing. That is the trade, and an even grid is worth it.

The alternative would have been to shorten every note to fit the shortest card,
which throws away real information to serve the layout. **Not doing that.**
