## What Q35 turned out to be

Not a build. **An extraction.** The glossary Sleven asked for already exists,
already sourced, already good — hover, tap, focus, Escape, reduced-motion, and a
`decorate()` that is opt-in per container and explicitly refuses to scan a whole
document "because that is how you end up with PDC underlined inside somebody's
ship name". It even refuses to invent a definition for a term it lacks.

**It ships on one page out of six.** Its own header says otherwise:

> "ONE GLOSSARY, ONE MECHANISM, EVERY PAGE - and it lives here because this file
> is injected into all of them."

`_layer.src.html` is not injected into anything. **It IS index.html.** Measured
on the deployed bytes, not the source:

    index.html     CC_GLOSSARY=4  cc-gl=8  data-gl=6
    find.html      0 0 0
    loadout.html   0 0 0
    keybinds.html  0 0 0
    holo.html      0 0 0
    download.html  0 0 0

So the file has claimed "every page" the whole time it was on one. That is the
same shape as the disclosure bar — which the glossary's own header cites as the
mistake it must not repeat.
