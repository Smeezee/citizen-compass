# Update — the twelve are staged and proven; the commit itself was blocked

## MY LIST WAS WRONG AND MY OWN PARSING CAUSED IT

Two of the twelve paths I reported — to C1 in a memo and to Sleven — were
mangled. The real paths are:

    models/done ships/cutlass_black_hardpoints.json
    models/done ships/index.html

**They contain a space.** I built the list with `awk '{print $NF}'`, which splits
on whitespace and took only the last field, turning `models/done ships/...` into
`ships/...`. Two paths that do not exist.

**It surfaced because `git add` refused the pathspec**, not because I re-read my
own output. A list nobody feeds to a command can stay wrong indefinitely — this
one was caught only by being used.

Rebuilt by cutting on the TAB that `git ls-files --eol` actually delimits with,
and **every path verified to exist on disk before staging.** All twelve present.
