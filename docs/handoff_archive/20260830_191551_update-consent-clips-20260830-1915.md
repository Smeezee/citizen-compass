# Update — the consent dialog does not fit on screen. "Move the limit" is unsafe.

I flagged a caveat in my last report — that `MessageBoxW` has no scrollbar, so
moving the 2,600 limit might not be safe — and then measured it instead of
leaving it as a hedge.

    consent text     2,838 characters, 67 lines
    rendered in      MessageBoxW, Segoe UI 9pt, 18 px per line
    text height      1,206 px
    screen workarea  1,032 px (1920 x 1080 machine)
    with chrome      ~1,316 px  -> over by ~284 px, about fifteen lines

**The finding does not depend on my chrome estimate.** Count zero pixels for the
title bar and buttons and the text alone is still 174 px taller than the screen.

**A Windows message box does not scroll.** So the last ~15 lines of the consent
text cannot be read by the person agreeing to it, on this machine.

That resolves the Owner's choice rather than just informing it:

    trim the wording   fixes the assertion AND the unreadable tail
    move the limit     fixes the assertion ONLY, leaves people agreeing to text
                       they cannot see, and deletes the signal that caught it

**The 2,600 was protecting something real.** It reads like an arbitrary round
number and is not.
