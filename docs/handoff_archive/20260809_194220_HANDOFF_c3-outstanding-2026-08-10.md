## 5. Two things from tonight worth carrying into the standing record

**The build-ordering defect Code found is the most valuable thing anyone found
today.** `inject_engine.py` ran after `index.html` had been assembled in memory,
so a `device_engine.js` change reached the index page only on the *next* build,
silently, with a comment above the call asserting the guarantee the code did not
provide. **Any past session that patched the engine and built once shipped a stale
index page.** That belongs in `CURRENT-STATE.md` independent of any order — and
right now it cannot be, because §1's canonical file is the stale one.

**Units belong in field names.** Two separate 50x-class bugs in two days, from the
same root: a number whose unit lived in someone's head. The four-ship file's `pos`
was centimetres, the viewer read metres, every marker landed fifty ship-lengths
out. Tonight's fleet file therefore calls its field `pos_model` and records
`model_units_per_metre` per ship — because the library turns out to hold **three
different scales**: 158 ships in metres, 8 normalised, 1 in centimetres, with
nothing anywhere recording which is which.
