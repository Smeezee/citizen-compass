## checks/_verify_correspondence.py — WRITTEN, GREEN, AND PROVEN

Mine per the new `OWNERS.md` line. **RULE16: INDEPENDENT** — the rules come from
`correspondence/README.md`, the procedure a human follows, and are spelled out in
the control rather than imported from `memo.go`. If the router and the README
ever disagree about what a memo is, this sides with the README.

Refuses: a file in a tray that is not a memo; a memo addressed to no real desk;
a memo sitting in the WRONG desk's tray (nobody reads that — the owner of the
drawer skips it as not theirs and the addressee never looks in it); an answered
memo with no answer under its `ANSWERS:` line; a tick instead of an answer; and
either status in the wrong drawer.

**An open memo is REPORTED, never failed**, exactly as Q47 and the README
require. A control that went red on an unanswered letter would make every
question block a deploy, and people would simply stop writing memos.

**Plus a DRIFT assertion:** the four desks are named in the control, and checked
against the README's own list both ways. A fifth desk added to the procedure
fails this control instead of going quietly unenforced.
