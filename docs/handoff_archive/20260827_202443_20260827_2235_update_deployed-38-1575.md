## THE BUILD REFUSED TO SHIP ON MY FIRST RUN, AND IT WAS RIGHT TO

    FIND DATA GENERATION FAILED - refusing to build. A page that reads a
    generated file must not ship beside a file the generator declined to write.

Cause: `ModuleNotFoundError: No module named 'dotenv'`. **The repo's bare
`python` is `C:\Program Files (x86)\Python311-32` and it cannot import
`app.database`.** The build must be run as `.\venv\Scripts\python.exe`, which
has it. `build_deploy.py` spawns every child with `sys.executable`, so the venv
propagates once the parent is right.

**Worth saying plainly: this is the fail-closed path working.** A stale
`find_data.gen.js` beside a page that reads it is exactly the silent success
rule 12 is about, and the build would not let it happen. Nothing shipped from
the failed run.
