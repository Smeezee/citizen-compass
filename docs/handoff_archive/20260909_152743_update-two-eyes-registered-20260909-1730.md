`--self-test` exits 1. Every failure path the wrappers own has been seen to go
red: a missing eye, an eye that exits non-zero, a table that lost a row, a blank
canvas, a readback that will not parse, absent playwright browsers, absent
payload. The two clean cases stay PASS.

wrapper's judgement, which is where every failure path lives — so the proof costs
1.1s rather than 11s, and it can produce a blank canvas on demand, which the real
eye cannot without breaking the viewer.
