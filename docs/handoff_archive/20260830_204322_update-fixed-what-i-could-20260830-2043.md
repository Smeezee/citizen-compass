## DONE — D8, the history log size policy

**Measured first:** 831 rows, 240 bytes each, 828 from a single run. Six runs a
day is ~1.2 MB/day, **~435 MB/year** — and `ReadHistory` loads the whole file
with `os.ReadFile`, so it was two problems.

**"Size policy" reads as "trim the old rows", and that was the wrong fix.**
`AppendObservations`' own comment states the property to preserve: *"no code path
here opens the file any other way"* — trimming would have added exactly that
path, to save bytes on a disk with hundreds of gigabytes free.

So it **rotates by rename** at 32 MB, and `ReadHistory` reads every rotated part
plus the live one, oldest first — a rotation that hid history would be worse than
the growth it fixed. A failed rename is reported and ignored, because refusing to
record a run over a stale file is the wrong trade.

Six tests. Three exist only to stop the fix being worse than the fault: a small
log is NOT rotated, the live log is not double-counted by the glob, and rotated
names sort chronologically (which "oldest first" depends on). **Mutation-proven
both ways.**

## DONE — the consent check was measuring the wrong thing

The assertion was `len(text) <= 2600`. **Characters are a proxy and the wrong
one.**

    to reach 2600 chars   lose 238 chars
    to fit the screen     lose 16 of 67 lines

**A text could satisfy the character limit and still run off the bottom**, and
the old check would have called that a pass. Added a second, stricter assertion
on LINE COUNT against the real geometry — 51 lines = (1032 − 110 chrome) / 18 at
Segoe UI 9pt — measured on the smallest display this is known to run on, because
the failure is invisible to anyone with a taller screen, which is how it
survived. It fires:

    [FAIL] CONSENT: the text fits on screen - a message box does not scroll
           the text is 67 lines; a 1032 px working area holds 51 at 18 px, so
           the last 16 cannot be read by the person agreeing to them

**It does not replace or relax the character check.** A stricter question about
the same text can only surface more truth.
