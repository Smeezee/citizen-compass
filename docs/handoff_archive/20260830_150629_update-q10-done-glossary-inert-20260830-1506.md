`loadout.src.html:4878` is ready and waiting:

**`window.ccGlossary` is undefined on loadout.html — `impl=false` above.** So
`glossPage()` returns on its first line, every time, and has always done so.

**That guard comment is the whole reason nobody noticed.** "layer absent: page
still works" turns a missing dependency into a silent no-op. It is the same
failure class as a gate returning 0 unconditionally: the page reports success by
saying nothing, and a feature Sleven asked for directly has never run.

**One false belief caused all of it** - that `_layer.src.html` is injected into
every page. It is stated in the glossary's own header and assumed by loadout's
guard. `_layer.src.html` IS index.html; it is injected into nothing.

The work is good. The terms are sourced, `decorate()` is scoped to six terms on
part rows, `#stats` is deliberately excluded because those rows already carry
`title`/`aria-label` and two tooltips on one row is worse than one. **None of it
has ever reached a person.**
