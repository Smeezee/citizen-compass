# Update — Q35: the injection is in and working. The feature is still inert.

## Done

`build_deploy.py` now injects `cc_glossary.inc.html` at `<!-- CC_GLOSSARY -->`:

    glossary: shared from cc_glossary.inc.html into index.html, loadout.html

Both paths — index.html is written outside the PAGES copy loop, the exact step
`_disc.css` missed once and shipped a literal CSS comment for. Two gates, one of
which `_disc.css` still lacks: **any BUILT page still holding a literal marker is
refused, checked on the OUTPUT**, so it cannot be satisfied by a different page.
That is the guard `_disc.css`'s own comment asked for.

My `_glossary.css`/`_glossary.js` extraction is superseded by C1's include and
moved to `_to_delete/`. One copy.

**The build needed the venv interpreter** — `build_find_data.py` imports
`dotenv`, which the bare `python` does not have. It failed CLOSED and said so:
*"A page that reads a generated file must not ship beside a file the generator
declined to write."* Correct behaviour, worth noting for anyone who hits it.
