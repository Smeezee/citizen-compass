# Update — The checks runner already existed. It could not run the suite.

**2026-08-27 22:00 · Code (background session)** — Sleven: *"do the checks
runner"*. Sweep re-running now; the finding is worth filing ahead of it.

## I did not write one, and that is the point

`checks/run_all_controls.py` already exists, 228 lines, and it is **good**. It
discovers controls on disk rather than carrying a typed list, it fails closed
("a control that cannot be run is reported as NOT RUN and counted against the
sweep… never reported as passed"), it has a `--self-test` that requires every
inverted control to exit NON-ZERO, and it has a 900s timeout whose expiry is
recorded as NOT RUN.

**Writing a second one would have been the duplicate-writer defect this repo has
been bitten by three times.** So I read it first and ran it.

## It crashed after 14 of 96 controls, on rule 15

    Exception in thread Thread-11 (_readerthread)
      ... cp1252.py, line 23, in decode ... charmap_decode
    UnicodeDecodeError

`subprocess.run(..., text=True)` with no encoding decodes the child with the
platform default. The controls print **ship names** — `Yeng'tu` and
`"Shredder"` carry curly quotes, `San'tok.yai` carries a macron — so the reader
thread died and the sweep stopped at 14 of 96.

**It failed loudly rather than silently**, which is the safe direction. But it
means the full suite has not been runnable, and a suite nobody can run is a
suite nobody is checking.

## Fixing the read moved the crash rather than removing it

Second run reached `_verify_child_markers.py` and died the other way:

    print(out.strip()[-1200:])
    UnicodeEncodeError: 'charmap' codec can't encode character 'ā'

**Rule 15 has two halves and this runner needed both** — the way in AND the way
out. That is the same pair I fixed in `build_deploy.py` and in two of my own
scripts earlier today, which is now five instances in one day of the same defect
in five different files.

Both fixed here: `encoding="utf-8", errors="replace"` on the subprocess, and
`sys.stdout.reconfigure` on the runner's own output.

## What it is NOT

It is not a new file, not a second runner, and not a change to what the sweep
means. The discovery, the fail-closed reporting and the self-test mode are all
as their author wrote them.

## Still running

The full sweep takes well over ten minutes — 96 controls, 8 of them driving a
real browser. Results in the next update, including anything that legitimately
fails.
