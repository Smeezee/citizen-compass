# RULING — the share card is SHAPE A. One static card, and the ship name is not worth what it costs.

**C1 (Claude-09), 2026-09-13, 05:2x CDT. Sleven put the choice to this desk — "you pick what's
best" — after settling the packed link and shelving the short code.**

## THE RULING

**Shape A. One set of Open Graph tags on the loadout page, the same for every build:** what
Citizen Compass is, that this is a ship loadout, and the dataset's patch. **No ship name.**

**Shape B — the ship in the path and 318 generated entry points — is not built, and it is not
"later". It has a trigger, written below.**

## WHY, AND THE FIRST REASON IS THE ONE THAT DECIDES IT

**THE CARD'S JOB IS NOT TO NAME THE SHIP. THE HUMAN ALREADY DID THAT.**

A shared build arrives inside somebody's own message — *"here's my Polaris build"*. **The ship name
is almost always in the sentence directly above the card.** A card that repeats it adds a second
copy of the one thing the reader already has.

**What the poster does NOT supply is what this site is, to somebody who has never heard of it.**
That is the only thing in that message speaking for us, and **it is the harder job and the one
worth the card's space.**

**Shape B spends the card on the redundant half and leaves the useful half unsaid.**

## THE SECOND REASON — WHAT B COSTS IS NOT THE STUBS

**318 generated files is not the problem; generating them is trivial from data we already hold.**
The cost is that **B creates a second entry point to the application and a new share-URL shape,
permanently.**

**Every future change to the loadout page's shell has to reach all 318** — fine while they are
generated from one template, and a live hazard the first time somebody edits the real page and
forgets the generator. **That is the two-places defect, and this project has paid for it three
times in one week.**

**AND B HAS A SILENT-WRONG FAILURE MODE THAT A DOES NOT.** If the per-ship stub hands off to the
loadout page by redirect or meta-refresh, **some clients drop the fragment — and the link then
opens a clean, empty loadout instead of the shared build, with no error.** A shared link that
silently loses the build is the worst outcome available here.

**It is avoidable** — the stub must BE a real page that loads the same scripts, never a redirect —
**but it is a constraint somebody has to keep honouring, and A has nothing to honour.**

## THE THIRD REASON — A IS NOT A COMPROMISE THAT HAS TO BE UNDONE

**A and B are independent.** Choosing A today costs nothing if B is ever wanted: the tags are
replaced, not unwound. **There is no debt in taking the cheap one first.**

## WHAT WOULD MAKE ME WRONG, STATED SO IT CAN BE CHECKED

**B's card is genuinely better AS A CARD.** Somebody scrolling past sees *"RSI Polaris — Citizen
Compass loadout"* and knows instantly what they are looking at. **I am not pretending otherwise.**

**THE TRIGGER FOR REVISITING, and it is a measurement rather than a feeling:** if shared links
become a real source of visitors AND we can see that people are not clicking them. **Until both
halves are true, B is a nicer card for no measured gain.**

**"Later" is not a trigger.** This one is.

## WHAT STAYS SETTLED

**The packed link, the fragment, the Discord paste test before ship, and the short code on the
shelf.** None of it is reopened and none of it depends on this ruling.

## WHAT DESIGN STILL OWNS, AND IT IS THE HARD PART

**The copy.** One card that has to introduce this site, in one line, to a stranger who has only
seen a friend's message. **That is a real design problem and it is not mine.**
