# SC Brain — Star Citizen intelligence inside Citizen Compass

**Status:** Named subsystem (2026-09-14). Architecture official definition.
**Not** a separate repo. **Not** a divorce from Citizen Compass.

---

## What it is
**SC Brain** = the one place inside Citizen Compass where all Star Citizen / Squadron 42 intelligence lives in a clean folder tree.

Same house. Dedicated wing.

- Citizen Compass = whole project (site, tools, mail, desks)
- Obsidian = window/graph on the same disk
- Brain 2.0 = find / fix / fetch / ask muscle
- **SC Brain** = the compiled SC knowledge shelves those muscles fill

---

## What it is not
- Not a second Citizen Compass
- Not “Smart Second Brain” the Obsidian plugin (that stays OFF by default)
- Not chat memory — files on disk

---

## What goes in it
Everything the god-mode constitution covers, compiled into one tree, for example:

- CIG firehose (patches, videos, social, jobs…)
- Build truth (LIVE / PTU)
- Creator claims (watchlist, non-verbatim)
- Bugs & workarounds
- Active orgs
- Ship / feature pipeline (announced | teased | speculated)
- Historian / continuity (Port Olisar → successor, Aurora Mk I store sunset, etc.)
- Lore / alien languages
- SQ42 cast & credits (spoiler-gated)

Exact folder map = later. Principle = **one SC Brain root**, not SC facts scattered forever.

---

## How it works with the rest
1. Existing tools gather (RSI sweep, p4k, collectors, UEX, wiki…)
2. Agents normalize and **file into SC Brain**
3. Site / ask layer **reads SC Brain**
4. Obsidian **graphs SC Brain** (and the rest of CC as needed)

---

## One-liner
**SC Brain is Citizen Compass’s Star Citizen library — same project, one compiled brain for the verse.**
