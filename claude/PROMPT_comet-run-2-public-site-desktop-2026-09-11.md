STEP 4 — FINDINGS. Look for navigation problems, missing information, ship information that is weak or unclear, accessibility problems, broken links inside this site, and visual inconsistency.

EVERY FINDING USES THIS FORMAT:
ID: P-001, P-002 ...
PAGE: the full address
CATEGORY: navigation / missing information / ship information / accessibility / broken link / visual inconsistency / first impression
LABEL: CONFIRMED, UNVERIFIED or OPINION
SEVERITY: blocks a task / slows it down / cosmetic
EVIDENCE: see the rules below

LABEL RULES:
- CONFIRMED needs BOTH exact steps anyone can repeat AND one of: a screenshot, the visible text quoted word for word, or the observed result of following a link on this site.
- UNVERIFIED is a problem you believe is real but could not prove to that standard.
- OPINION is a judgement: say what a first-time visitor would probably do, and why.
- Accessibility can only be CONFIRMED by an actual test: moving through the page with the keyboard alone, or checking text contrast. Anything else about accessibility is UNVERIFIED or OPINION.
- If part of the page would not load or show, report that as its own finding. Do not guess what it contains.
- Do not suggest code or technical causes. Describe what a visitor experiences.
- No evidence, no finding.

END WITH:
1. A count of CONFIRMED, UNVERIFIED and OPINION findings.
2. The three findings you would fix first, by ID, and why.
3. EXTERNAL LINKS: every link that leaves this site, as its visible text and its address, not opened.
